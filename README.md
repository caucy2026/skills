## 安装

将所需技能的整个目录复制到 `~/.codex/skills/`；不要只复制 `SKILL.md`。本仓库不包含 Codex 系统内置技能、运行缓存、凭据、私钥或虚拟机文件。

使用前完整阅读对应 `SKILL.md` 及其要求的引用文档。上传成功不等于发布完成，编译成功不等于功能验收通过；结果以技能规定的实际验证证据为准。
