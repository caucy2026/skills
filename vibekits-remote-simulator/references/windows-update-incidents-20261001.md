## 路径、参数和证据的常见误判

- xzl 只有 C 盘：使用已授权的用户本地实际安装路径和结果目录，不机械指定不存在的 D 盘；签名设备 58 仍遵守其 D 盘规则。
- Robocopy `/LOG:` 必须作为一个完整参数传入，PowerShell 使用 `('/LOG:' + $logPath)`。退出码 0–7不等于失败；核对源/备份文件数与主程序哈希才允许安装。本次首次错误参数在复制前失败，修正后 29935 文件副本及主程序哈希核对通过。
- `ssh_exec` 整条命令最大 8192 字符。长固定源码使用 `upload_file`；SFTP 尚未修好时可分块传送固定源码、合并后核对完整哈希。不要超限后反复原样发送。
- 签名会改变文件大小和哈希；早先缓存的 `FileInfo.Length` 可仍是签前大小。必须签名后重新 `Get-Item`、重新算 SHA256，下载和上传后再次核对。
- `runtime.status` 是代理/VM 状态，不是 Harness 健康检查。必须发起明确无副作用的 `session_prompt`、等待同一次 session 完成，并按时间或 requestId 从历史中确认本次实际公开回复，不能把历史回复当作本次证据。
- 集群继续保留已信任的 HTTPS origin、CA 和公钥，填写控制端仿真 ID 路由。不要为绕过证书错误关闭校验。已批准成员身份不等于具备任意任务执行授权；有效任务上下文门禁不能删除。
- 独立 Flutter 测试目录要复用现有 package_config、package_graph 和必需资产引用，输出只写自己的外盘目录。本次补齐缺少的依赖图和 test_data 引用后单项测试通过，没有下载依赖或使用共享 build。

时间戳代理 502 及安全恢复已记录在全局技能 `market-app-update.md`：使用官方健康入口验证、只调整时间戳域名的代理例外，并核对 finally 恢复及实际注册表值；不要把时间戳根 URL 的 HEAD 结果当作服务健康证明。
