# 远程仿真通道断开分层诊断

`Remote desktop is offline` 表示仿真路由当前不可用，不等于目标电脑关机，也不等于远程办公通道离线。先记录时间、目标仿真 ID、错误原文和发起端版本。按顺序检查发起端 VibeKits 主进程/Harness/本地桥，再检查仿真连接与状态；若另有已授权的可信管理通道，核验目标主机身份后只读检查目标 VibeKits 进程、登录会话、仿真开关及网络/中继登记。不得因远程办公进程在运行就推断 VibeKits 仿真已开启，不得从非交互 SSH Session 0 声称 GUI 已启动。恢复后必须以相同仿真 ID 重新连接，验证返回的设备身份和 `p2p_or_relay`，再检查版本与目标任务。
