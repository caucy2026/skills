# macOS 远程文件访问权限

用户现场截图确认的系统入口：**系统设置 → 通用 → 共享 → 远程登录旁的 ⓘ → 允许远程用户完全访问磁盘**（部分系统文案为“允许远程用户对磁盘进行完全访问”）。仿真客户端通过 macOS 的 SSH/远程登录访问受隐私保护的本地文件时，如需此权限，应检查这个入口，而不是反复改文件权限或重新安装客户端。

先核原设备/用户、实际失败的文件路径、使用的是SSH还是App文件工具，以及具体拒绝原因。SSH已能登录但受保护文件返回Operation not permitted，与主机离线、SSH身份认证失败、文件不存在、普通Unix权限不同，不能混为一谈。只核必要路径，不扫描用户私有目录或输出文件内容。

该开关适用于远程登录用户；不能据它推断VibeKits自身、文件选择器或其他App已获完全磁盘访问。App文件工具受拒时，另核实际签名App及它的系统隐私权限，不把SSH开关当成所有通道的统一授权。

沿用户已授权的设备和任务范围说明所需权限；新增敏感访问仍遵循平台当次确认和身份核验，密码/PIN由本人在设备窗口输入。不得通过关闭SIP、重置TCC、清授权或放宽全盘Unix权限来替代。开启后，用原ID、原用户和原失败路径做最小读回，记录成功/拒绝及实际范围；不要仅凭开关为蓝色宣称已可访问全部文件。
