# Windows 远程桌面辅助恢复

App无法启动、SSH故障或仿真访问待确认时，沿用用户授权的远程桌面恢复，再返回原仿真ID。完整案例读取当前VibeKits项目docs/acceptance/WINDOWS_388630819_REMOTE_DEBUG_2026-10-03.md和WINDOWS_SERVICE_COMPATIBILITY_OFFICIAL_RUNBOOK_2026-10-03.md，不将案例路径作为通用固定路径。

1. 核对桌面ID、实际主机和仿真ID关系；记录旧版路径、签名、主机指纹和权限，冻结完整候选与回退。
2. 分开诊断App崩溃与SSH故障。核查CRT/WebView/Node/relay完整性，采用真实事件与必要转储，不能依赖开发机PATH。
3. SSH使用detect→plan→backup→apply→verify→commit/rollback。解析真实服务PathName/-f/HostKey与监听者，健康既有通道复用；不杀未知监听者。
4. 388实测默认三把主机私钥由普通用户拥有且有Modify，logs正常，SCM1067。目标端备份SDDL/SHA后仅改这三把Owner为SYSTEM、限定SYSTEM/Administrators完全控制，字节不变，SCM Running恢复。不能把此因果推广为所有1067；自定义配置及普通用户独立daemon必须另查。
5. 新增敏感访问须动作时精确确认。用户此时明确要求代理通过远程桌面允许后，可点击同一请求的允许及原生确认，无须重复提问。核对请求者、目标、身份摘要/requestId。过期只重发一次，不自动批准陌生或扩大范围请求。一般独立完成不是任意未来权限的永久批准；平台要求人工接手的密码变更等仍需接手。
6. 388两层确认后原ID6175875975新认证成功，原指纹保持，系统服务PID16100与IPv4/IPv6端口22一致，MCP内层ok。弹窗消失和绿灯不能替代这些验证。
7. 同身份升级前全备份、验签与完整依赖检查；App之外独立守护，覆盖后原ID认证、MCP及SFTP往返SHA并限时原子提交。超时回退不能用瞬时健康追认。保持ID/密钥/原有效权限。
8. 同一包三Windows测试真实启动/退出重启、工作区、模型、权限连续性和空闲CPU；旧版或未测BLOCK。清理本任务临时文件/自建进程，保留证据与必要回退，复查原服务。

统一兼容算法须检测OS/架构/PS及实际服务类型，分类支持范围、组件、配置、目录/主机私钥ACL、端口、认证与SFTP故障，只修证实缺陷。服务维护与App更新分离，健康端点幂等保持，失败精确回退；不得每版重建身份。三台是回归样本，不能宣称所有历史Windows通过。


## 388最终签名候选恢复补充

详细时间线和证据阅读上述项目案例的“18:49–18:52 最终签名候选与关键点复盘”。独立更新入口必须留在App外并存活至守护终态；只读备份进程在观察SSH断开后可能继续，先查真实终态再重试。远程输入不完整时取消，不执行截断命令。连接状态缓存不能算新握手，提交后明确断开/重连核对原指纹。Limited任务看见PID却读不到路径时，分类权限上下文，不能据null盲杀或重装。

388的446已实际提交，但运行在诊断目录，原dev232目录未覆盖；模型/最终冷启动/全进程族CPU未完成，禁止抹掉这些限制。案例成功步骤不授权未来未知设备或扩大权限，不保证所有Windows版本。


## 证据误判与采样纠偏（本次实际教训）

- 首先读取案例文档的阅读路线及当前终态；按时间区分旧dev232、445诊断与最终446。只复用方法，不能跨产物借用PASS。
- Windows凭据按当前令牌的登录会话区分。SSH CredRead错误1312不等于用户交互会话的凭据不存在；cmdkey输出包含目标字符串也不构成证明。确需核查时，在获授权同一用户交互任务中只读存在性/错误码，不读取凭据值；1168是该上下文未找到，没有升级前基线不能断言升级丢失。官方依据：https://learn.microsoft.com/en-us/windows/win32/api/wincred/nf-wincred-credreadw 。
- CPU记录实际进程族、原始kernel/user增量、采样时长、RSS及缺失PID；宿主总CPU排除PID0空闲进程。既定单核等效门禁不得除以逻辑核数改变口径。累计CPU时间不等于CPU百分比；线程快照全零与进程计数矛盾时换可靠计数器，不宣称空闲。
- 388最终446的313.68秒/60样本族CPU中位19.14%，最小化短对照主程序7.43%，仍未通过；没有精确调用栈或修复后复测就不写根因关闭。线程描述为空就保留为空，不能编造UI/raster标签。
- 远程画面时间戳落后时先区分观察通道与App状态；只重连本任务目标桌面，不据旧帧重复点击、安装或重启共享服务。输入法可能留下未提交草稿，核对完整输入及真实提交，不把Escape当清空证明。
- 独立采样任务注册成功不能证明工作进程存活；核对PID/父进程/路径和终态结果。SSH输出被截断时，经SFTP下载已知本任务原件并校验长度/哈希，不重复执行原测试。下载必须使用绝对路径；桥接路径校验失败不能归为远端SFTP故障。
- 回收限定为已结束且确认为本任务的计划任务、脚本、临时窗口和诊断产物；继续调查时保留必要回退和证据，并写明未清理原因。原安装入口没有替换或任何硬门禁失败时，不宣称整机升级或商城发布成功。
