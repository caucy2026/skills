# 已证明的测试前置与误判

- Android逻辑display与screencap物理id可能不同；动态ADB串口从原仿真ID本次响应提取，不写死IP。新UI dump失败不能读旧XML。键盘模式字段/窗口/几何共同校验，开关回执opening不等于visible，发Back不等于窗口已关闭。
- 接收目标须自建、精确PID/窗口/原文保护；不向客户既有文稿注入测试。Mac激活和前台核验在发按键的同一执行器立即进行，工具调用本身可能夺前台。无输入的短对照仍有键时先查并发/环境，不认定远控异常，也不停止别人的进程。
- Windows SSH通常Session0；客户窗口是Session1/其他会话。Session0空UIA不能证明客户窗口不存在。使用项目既定交互任务/代理，在已登录用户Limited会话观察自己的接收器并回读自己的D盘证据。临时任务精确名称、Description、动作hash核验后只清理自己；没有D盘不写C盘载荷。
- 跨机时钟可能有偏差；接收数据新鲜度在接收机本机时钟计算，或用序号推进，不改客户系统时间。Python3.9需要处理.NET七位小数；观察器解析错误发生在动作前时不得计产品失败。
- PowerShell命令用UTF16LE EncodedCommand；这不保证SSH stdout中文编码。自建UTF8 JSON以ASCII Base64回传并严格解码，保存原损坏输出和正确原文；WinForms回车通常CRLF，Mac文本通常LF，保留原始换行断言。
- F/N拼音联想可能先消费退格清候选，再删正文，依据真实配置/源码和预编辑状态；不能套用到G实体按键路径。候选坐标须来自当前布局，不以正文无变就说丢键。
- 静态页面可能无新视频包。先用自建动态内容，再核验双路解码及GPU呈现推进；不要因静态帧龄增长改解码器。自己的临时标签按唯一URL/身份核验清理，不能关闭别人的标签。
- 扩展灰显必须记录实际enabled/clickable、当前peer和重复新会话，再查宿主能力/安装/服务/权限及历史；有驱动或电脑版本号本身不能证明协议能力已广告，不直接强行启用按钮。
- 控制桥不可用先查本机主App/桥PID及成熟locator；仅relay存活不等于主程序在线。正常打开现有App并按原ID/指纹恢复，不重装远端，不杀全局ADB，不把仿真中断当远程桌面断线。
